# Security Policy

## Supported Versions

This repository is pre-1.0 and is not published to npm. Security fixes are
handled on the latest `main` branch.

## Reporting a Vulnerability

Do not include exploitable vulnerability details in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use
the repository's Security tab to report a vulnerability privately.

If private reporting is unavailable, use the contact details on
https://matthiaslettl.com/ or open a minimal public issue asking for a private
security contact, without exploit details.

We will review reports as quickly as practical and coordinate a fix before
public disclosure.
